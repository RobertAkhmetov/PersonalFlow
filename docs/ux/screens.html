Оболочка и общие состояния

Avalonia для ПК использует боковую навигацию и соседнюю область деталей при достаточной ширине. MAUI Blazor на телефоне использует вкладки «План», «Уроки», «Заметки». Первое открытие ведёт к текущему дню. Каждая вкладка восстанавливает собственный выбор и прокрутку. При узком окне или увеличенном тексте детали занимают всю ширину. Вход выполняется в системном браузере.

Шаблоны компонентов: карточка дня, строка задачи, редактор с черновиком, выбор даты, ссылка на источник, строка сообщения, индикатор синхронизации, сравнение значений. У каждого интерактивного элемента есть доступное имя, видимый фокус и действие с клавиатуры. После закрытия панели вернуть фокус к вызвавшему элементу. Статус передаётся текстом. Жесты дублируются командой в меню.

При первом открытии различать загрузку, отсутствие кэша и действительно пустой список. При обновлении продолжать показывать сохранённое содержимое. После локальной записи показать «Сохранено на устройстве», подтверждение сервера закрывает ожидание. Ошибка записи оставляет ввод доступным. Для опасного действия указать цель, масштаб и последствия. Личные данные отделены от демопрофиля.
